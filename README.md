# ANTSOFT Key Manager search (Python 3.9)


If you use ANTSOFT Key Manager and you need to find something among the actions, this program will help you!

## Instructions

### Launch
> Before launching, make sure that your "key manager" is launched

### Search
> To find something, type the string you're looking for in the top textbox and click the "Find" button. The program will scroll through all folders and actions and display all occurrences of the searched string in the lower field
